# Martin_Estiven_Guiral_Restrepo_Ejercicio_4

Historial de operaciones de un cajero

Objeto Operacion
•	numeroOperacion 
•	tipo 
•	valor 
•	fecha 

El sistema debe permitir:
1.	Registrar una operación. 
2.	Deshacer la última operación. 
3.	Consultar la última operación realizada. 
4.	Mostrar todas las operaciones almacenadas. 

Objetivo: simular la función "Deshacer" utilizando una pila.
